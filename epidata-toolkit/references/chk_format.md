# EpiData chk 检查文件格式规范（标准格式）

.chk 与 .qes/.rec 同名，定义数据录入时的**质控规则**（必填、范围、合法值、跳转）。EpiData 打开 qes 时若同目录存在同名 chk 自动加载。**必须以标准格式书写，编码 GBK + CRLF + 无 BOM。**

## 字段块结构（用户锚定，不可偏离）

```
REPWAY                    ← ①字段头：裸字段名，无花括号{}、无缩进
  RANGE 1 5               ← ②属性行：缩进2空格，上下限空格分隔，无等号、无连字符
  LEGAL                   ← ③子块开启：缩进2空格
    1                     ← ④子块内容：缩进4空格，每个合法值一行
  END                     ← ⑤子块结束：缩进2空格（与属性同级）
  JUMPS                   ← 子块开启：缩进2空格
    5 REPWAYO             ← 跳转规则：缩进4空格，值 + 空格 + 目标字段（无冒号）
  END                     ← 子块结束：缩进2空格
  MUSTENTER               ← 属性行：连写无空格
END                       ← ⑥字段块结束：无缩进
```

## 规则要点

| 规则 | 格式 | 说明 |
|---|---|---|
| 字段头 | `字段名` | 裸字段名，**不写 TYPE**（类型由 qes 掩码决定） |
| 范围 | `  RANGE 1 5` | 上限下限**空格分隔**；日期同理 `  RANGE 01/01/2020 31/12/2026` |
| 合法值 | `  LEGAL` 子块 | 每个合法值一行（缩进4），`  END` 结束；**与 RANGE 互斥，只能二选一** |
| 跳转 | `  JUMPS` 子块 | 每行 `值 目标字段`（缩进4），`  END` 结束；目标可用字段名 / NEXT / END / WRITE |
| 必填 | `  MUSTENTER` | 连写无空格；可显式 `required` 或自动推荐 |
| 空字段 | — | **无检查命令的字段不写入 chk**（官方规范：if there are no Check commands, then nothing is written）；只有字段块整体有规则才生成块 |

**未确认/不使用**：TYPE、AUTOENTER、NOENTER、KEY、REPEAT、VERIFY、BEFORE/AFTER ENTRY 等结构一律**不生成**（待用户提供标准样例后再支持）。

## 生成器规则映射（chk_generator.py）

| 字段 JSON | 输出 |
|---|---|
| `options: [...]` | `LEGAL` 子块（选项编号逐行） |
| `legal: [1,2,5]` | `LEGAL` 子块 |
| `range: [1,120]` 或 `"1-120"` | `  RANGE 1 120`（有 options 时忽略，互斥） |
| 无 range 无 options 的数值字段 | **自动推断** `RANGE`：字段名/标签命中保守表（年龄 0-120、体温 30-45），显式 range 优先 |
| `required: true` | `  MUSTENTER` |
| 未配置 required 的字段 | **自动推荐**：核心字段名精确匹配（NAME/SEX/AGE/OCCUP/ONSETDT/OUTCOME/ADDRESS/MOBILE/TEL 等）、标签命中核心关键词、或含"不知道/不详"兜底选项 → `MUSTENTER`；`--no-auto-required` 关闭 |
| `jumps: {"2": "FIELD"}` | `JUMPS` 子块（`2 FIELD`） |
| 选项含"其他/其它"且存在注明字段 | **自动** `JUMPS`：其他编号 → 字段名+O（与显式 jumps 合并，不覆盖同值） |

## "其他"选项跳转（自动规则）

字段选项含"其他/其它"（如 `【5】其它`）时，qes 生成器**自动**补齐注明字段 `字段名+O`（如 REPWAY→REPWAYO，label 取选项原文），chk 生成器**自动**添加跳转 `其他编号 注明字段`，录入选"其他"即跳到注明栏填写。注意：
- 注明字段自动补齐：无需手工在 JSON 定义 `name+O`；若 JSON 已显式定义同源注明字段（`name+O` 或 `name[:-1]+O`，兼容 HANDWASO 式简化命名）则跳过，不重复生成
- 显式 `jumps` 与自动规则**合并**，同值不覆盖（如 OUTCOME 显式 1/2 + 自动 3→OUTCOMEO）
- 含"其他/其它"选项的字段**100% 有跳转目标**（注明字段由生成器保证存在）
- 注明字段自身（如 REPWAYO 的【5】其它____）不会再产生二级跳转（目标字段不存在时自动规则不触发）

## 必填字段选取原则

- 核心信息设 `MUSTENTER`：一般情况（姓名/性别/出生日期/现住址/手机/职业）、发病日期、核心暴露史、最终诊断、转归、调查单位/时间/签名
- **有"不知道/其他"兜底选项的暴露史字段**（如接触禽类【3】不知道）可放心设必填，不会卡录入
- 条件性字段（家长姓名、出生日期不详时的年龄等）不要简单设必填；二选一逻辑待 EDL 结构确认后再支持

## 生成后校验清单

1. 字段块数 = qes 字段数，字段名一一对应、顺序一致
2. 首行裸字段名；块末 `END` 无缩进；子块 `END` 缩进2；子块内容缩进4
3. 同一字段 RANGE 与 LEGAL 不同时出现
4. **全部 JUMPS 目标字段必须存在**（除外来 NEXT/END/WRITE）
5. 含"其他"选项的字段全部有对应跳转（注明字段自动补齐，目标必然存在）
6. 必填（MUSTENTER）字段逐一核对合理性，无"卡死录入"的字段
7. 编码 GBK 可解码、行尾 CRLF、无 BOM

## 校验清单

1. 字段块数 = qes 字段数，字段名一一对应、顺序一致
2. 首行裸字段名；块末 `END` 无缩进；子块 `END` 缩进2；子块内容缩进4
3. 同一字段 RANGE 与 LEGAL 不同时出现
4. RANGE 上下限空格分隔（`RANGE 0 120`，不是 `RANGE = 0-120`）
5. 无 TYPE / MUST ENTER（带空格）等非标准写法
6. 编码 GBK 可解码、行尾 CRLF、无 BOM
