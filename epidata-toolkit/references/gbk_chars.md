# GBK 字符集实测对照表（EpiData 3.1 中文版）

> 基于 Python `str.encode('gbk')` 实测（2026-10）。EpiData 3.1 中文版只支持 GBK，
> 生成 qes/chk 前先确认字符可编码；qes_generator 已内置自动替换。

## 一、GBK 原生支持（可直接使用，无需替换）

| 类别 | 符号 |
|---|---|
| 温度/单位 | `℃` `μ` `°` `′` `″` |
| 数学符号 | `±` `×` `÷` `≤` `≥` `≠` `≈` `√` `∞` |
| 箭头 | `→` `←` |
| 罗马数字 | `Ⅰ Ⅱ Ⅲ Ⅳ Ⅴ Ⅵ Ⅶ Ⅷ Ⅸ Ⅹ Ⅺ Ⅻ` |
| 标点 | `…` `·` `—` `–` `―` |

**示例**：`最高体温：##.# ℃`、`白细胞：×10⁹/L`（上标部分见下）、`分级：Ⅳ级` 均可正常 GBK 编码。

## 二、GBK 不支持（生成器自动替换，无需手工处理）

| 字符 | 自动替换为 | 示例 |
|---|---|---|
| 上标 `⁰¹²³⁴⁵⁶⁷⁸⁹` | `^0`…`^9` | `×10⁹/L` → `×10^9/L` |
| 下标 `₀₁₂₃₄₅₆₇₈₉` | `0`…`9` | `CO₂` → `CO2` |

生成时如出现提示 `⚠ 已自动替换 GBK 不支持字符 N 处`，说明有上标/下标被自动改写，
这是正常行为；替换后仍报错则说明存在替换表之外的字符，需手动改为 GBK 支持写法。

## 三、最佳实践

- 尽量写 ASCII 兼容形式：`×10^9/L`、`CO2`、`IV级`
- `℃` 可用（GBK 支持），不必改写
- 若 PDF/Word 原文含生僻字（生僻汉字、特殊 Unicode），先转写为常见字
